# Контрольные вопросы

**1. Чем класс отличается от объекта?**
Класс — шаблон (чертёж), описывающий свойства и методы. Объект — конкретный экземпляр класса, созданный через `new`, со своим независимым состоянием.

**2. Для чего нужен конструктор и когда он вызывается?**
`__construct()` задаёт начальное состояние объекта (заполняет свойства, проверяет аргументы). PHP вызывает его автоматически в момент `new`.

**3. Что означает `$this` и почему он недоступен в статических методах?**
`$this` — ссылка на текущий объект внутри его методов. Статический метод принадлежит классу и вызывается без объекта (`Класс::метод()`), поэтому «текущего объекта» нет.

**4. Чем отличается `$obj2 = $obj1` от `$obj2 = clone $obj1`?**
Присваивание копирует ссылку на тот же объект: изменения через `$obj1` видны через `$obj2`. `clone` создаёт новый независимый объект с копией значений свойств (копия поверхностная: вложенные объекты остаются общими, если не определён `__clone`).

**5. Чем статическое свойство отличается от обычного? Как к нему обратиться?**
Обычное свойство есть у каждого объекта своё; статическое одно на весь класс и общее для всех объектов. Обращение: `Класс::$свойство`, внутри класса — `self::$свойство`.

**6. Что такое readonly-свойство и когда его можно присвоить?**
Свойство (PHP 8.1), значение которого можно задать только один раз и только из области видимости класса, обычно в конструкторе. Повторная запись даёт `Error: Cannot modify readonly property`.

**7. Что такое продвижение свойств в конструкторе?**
Синтаксис PHP 8.0, при котором модификатор доступа у параметра конструктора (`__construct(private string $name)`) одновременно объявляет свойство и присваивает ему значение.

**8. Как реализовать цепочку вызовов методов?**
Каждый метод в конце делает `return $this;` и объявляет тип возврата `static` (или `self`). Тогда можно писать `$obj->a()->b()->c()`.

**9. Назовите три магических метода и случаи, когда PHP их вызывает.**
- `__construct` — при создании объекта (`new`);
- `__toString` — когда объект используется как строка (`echo $obj`);
- `__get` / `__set` — при чтении / записи недоступного или несуществующего свойства; `__call` — при вызове недоступного или несуществующего метода; `__destruct` — при уничтожении объекта.

**10. Чем `protected` отличается от `private` при наследовании?**
`protected` доступен внутри класса и его наследников, `private` — только внутри самого класса, наследники его не видят.

**11. Что делает ключевое слово `final`?**
Запрещает переопределять метод в наследниках (`final public function`) или наследовать от класса (`final class`).

**12. Как работает `spl_autoload_register`?**
Регистрирует функцию-загрузчик. Когда PHP встречает неизвестный класс, он вызывает зарегистрированные загрузчики по очереди, передавая полное имя класса; загрузчик должен подключить файл с классом (обычно через `require`).

**13. Как стандарт PSR-4 связывает пространство имён и путь к файлу?**
Префикс пространства имён сопоставляется базовой папке, остаток имени превращается в путь: `\` заменяется на `/`, добавляется `.php`. Например, при `App\` → `src/` класс `App\Models\User` лежит в `src/Models/User.php`.

**14. Когда нужно выполнять `composer dump-autoload`?**
После изменения секции `autoload` в `composer.json` (новый префикс или папка), а также при использовании classmap, когда добавлены новые классы. Для нового файла внутри уже зарегистрированной PSR-4 папки (при обычном режиме) повторная генерация не нужна.
